## Active

- [ ] Extension runs exclusively on Google Chrome (initial release).
- [ ] Extension uses Manifest V3.
- [ ] Hide YouTube Shorts elements from the YouTube homepage, sidebar, and search results.
- [ ] Hide Instagram Reels from the Instagram feed and sidebar.
- [ ] Hide TikTok feeds (or redirect if viewing the main feed).
- [ ] Provide a Popup UI to toggle the visibility of short-form videos on/off.
- [ ] Provide options in the Popup UI for additional settings.
- [ ] Keep a high-quality, up-to-date `README.md` for GitHub.

## Out of Scope

- [Support for Firefox/Edge] — Will focus on Chrome first to iterate quickly; cross-browser compatibility will be added in future features.
- [Full domain blocking] — The extension must only hide distracting elements, not completely block access to URLs like `tiktok.com` or `youtube.com`.
